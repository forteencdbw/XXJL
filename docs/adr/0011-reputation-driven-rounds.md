# 用声望名单取代 90 秒倒计时

此前每局是固定 90 秒：到点就打烊，一局来多少人取决于到店间隔，玩家永远不知道今天还剩几位。现在改成**名单制**：开市时按「声望」等级锁定当天客人总数（5 → 16 位），名单上的客人全部离店后自动收摊；没有倒计时，也没有「最后 10 秒不再接客」。

理由有三条：

1. **倒计时和目标互相打架**。每日目标里的「接待 N 位」在固定时长下只能靠随机到店间隔碰运气；名单制让「今天有 5 位客人」变成可以规划的事实，目标、菜单和备货才有意义。
2. **需要一条长线成长轴**。酒楼等级只扩座位，不决定客流；声望是第一个「你在这个世界有多出名」的数值，服务客人 +10、气走客人 −20，九级称号从「无名小馆」到「仙凡共仰」，级别直接决定明天来几位客人、以及稀客（长老/魔道）的比例。它把「今天服务得好不好」累积成跨天、跨几十天的东西。
3. **节奏要慢下来**。顾客从队列走到雅座的基础时长从 1.2s 提到 1.9s，各类进场动画 ×1.5，一局从 90 秒变成约 2–5 分钟，配合「服务完所有客人」的终局感，让一局像一段完整的营业，而不是一段掐表的冲刺。

代价与取舍：

- **「到店间隔」不再是核心数值**。门面招幡、迎客伙计、元婴境界原本都靠缩短间隔生效，在固定名单下会变成「来得更快反而更容易溢出」。本期直接**拆除这三个效果**，招幡与迎客保留可买、标「效果待重做」；元婴暂无加成。新机制待定。
- **每日目标砍掉「接待」类**，只剩「本日收入 / 满足口味」两张卡——接待人数现在是固定值，不再是一道选择题。
- **天时与灯会改吃人数**：晴 +12%、夜雨 −12% 直接作用在当天总人数上，灯会 +3 位。
- **存档升到 v2**，v1 旧档与 `LS1.` 导出码一律拒绝，不做迁移。声望随破产清零；飞升后的归属暂未决定，等飞升机制单独讨论。
- **经济需要重调**。9 级 31% 的稀客率（客单价 1.8–2.5×）叠上人数从 5 涨到 16，收入曲线比旧版陡得多，日租、工资、目标值与破产阈值都要另跑一轮试玩再定。

未决：人物特写（看卡时排队耐心是否暂停）、门面/迎客/元婴的新机制、飞升与声望的交互。
