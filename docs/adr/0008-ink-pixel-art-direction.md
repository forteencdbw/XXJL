# 整体转向水墨像素风

2026-10-25，真人试玩与截图评审都把上限指向同一处：程序化平滑矢量人物在 390 屏上太小、太像纸片，第一眼和人物可看性上不去；但整套美术又不足以直接换成手绘资产。用户明确选择「整体转水墨像素风」，因此把视觉系统改成：

- **像素底图 + 楷体题字**：场景、人物、图标用低分辨率像素网格绘制，再用最近邻放大；中文标题与按钮文字保留楷体，保证手机可读。
- **水墨限定色**：墨黑、靛青、暖纸、朱砂、旧金五色为主，不用高饱和青色/紫色；光用抖动像素与暖色点阵表现，不用大面积平滑渐变。
- **先定标题，再逐屏替换**：标题页已换成 360×640 的像素底（月、雾、山、两层屋檐、窗火、灯笼、松竹），再用 2× 最近邻铺满画布；打烊页换成同一套像素酒楼底图与朱砂/旧金事务卡，菜单的目标卡/菜行/开张按钮改成墨底 + 朱砂。后续顺序是人物与队列间距、店内背景、结算/账簿。
- **人物需要重新排版**：48×64 像素精灵在 390 屏上以 1.35 倍显示；队列间距 34→84、桌子横向范围 350→500，给人物和 4–7 桌留位置。特写卡暂留平滑矢量，作为近景立绘；营业内景背景仍平滑，是下一屏要转的部分。单独换人物会和背景割裂，但先解决“人看不见/无五官”的问题，再逐屏替换背景。
- **文字不进像素网格**：中文像素字库缺失，强行像素化会牺牲可读性；字体继续用楷体，框体、图标、底图走像素。

代价：平滑的柔光、纸纹、渐变灯笼需要逐屏替换成抖动/点阵；过渡期会有一段时间的风格混搭。至少在标题、打烊页、菜单、营业内景四屏统一之前，不宣称美术方向完成。
