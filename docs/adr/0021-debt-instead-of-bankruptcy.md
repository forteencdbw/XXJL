# 欠债不破产：余额为负只冻结扩张

取消破产。余额为负进入**欠债状态**：营造、雇人、刷新招聘本就要求现金充足，欠债时自然做不了；**常客不登门**（名单保留，还清即恢复）。不清档、不扣声望、照常营业与领奖。`bank.bankruptStreak`、`BANKRUPT_STREAK`、`bankrupt` 标志、破产弹窗与 `freshSave` 一并删除，`negativeStreak` 保留为"连续欠债天数"，只用于结算单/商行/状态栏提示。

为什么：破产会清零灵石、等级、伙计与声望，是唯一会回退大量已投入时间的设计，和 ADR-0020 冲突。扩张冻结已经提供了压力——欠债期间赚不到扩建，规模会停住。

代价：

- 经营失败从"终局"变成"变慢"，日租与工资的威慑力下降；若实测太松，可加更硬的可逆压力（欠债期客单价下浮），不要回到清档。
- 贷款 12 期还款可能把余额长期压在负数，借款玩家会被冻结扩张，需要实测借款节奏。
- 旧的"破产重开"存档兼容路径（`freshSave`）消失；现存 localStorage 里不会再有破产态，因为破产本身已不存在。
- `negativeStreak` 改名不改字段，存档版本不变。
