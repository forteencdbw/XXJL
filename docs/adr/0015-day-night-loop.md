# 昼夜循环：白天营业、夜里修行

打烊不再是一个可以无限停留的菜单界面，而是一段有时钟的**夜修**：子初结算后进入夜修视图，时钟按营业同样的节奏（约 4 秒一刻）从子初走到辰正，走满才弹出开张提醒。核心循环因此变成「白天经营酒楼 → 夜里提升修为」交替。夜修不能跳过，进度写入存档。打开任何子系统页面时，整个店的时间（白天的营业与夜里的夜修）一起冻结。

为什么：修为子系统要有自己的舞台，而不是营业之外顺手点一下的页面。给夜晚一段真实时长，修行玩法就有了固定的时间预算，和白天的经营节奏对称。子系统暂停是为了让玩家在任何时候都能放心打开页面去规划，不会因为看了一眼伙计或修为就让客人排队超时、夜修白白流走。

代价：

- 修行玩法做出来之前，每晚约 2 分半基本只能排人、营造、备货，玩家会有一段空等；夜修时长在 config 里可调。
- 夜修进度要存档，否则将来修为在夜里有产出时，玩家可以靠刷新反复刷。
- 暂停冻结的是整个场景的时间，所有计时都必须跟着游戏时间走，不能读现实时钟。
