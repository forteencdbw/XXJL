# 用 Phaser 而不是 PixiJS 作为游戏框架

本项目要在微信/抖音小游戏和 TapTap（H5）上发行一款餐厅经营放置类游戏，开发方式是由 agent 写代码而非作者手工打磨引擎细节。此前作者有 PixiJS 的发行经验，但 PixiJS 只是渲染层，场景管理、输入、音效、Tween 动画、资源加载都要自己拼或另找库，这类胶水代码对 agent 生成而言样板多、易踩坑。Phaser 是构建在 Pixi 渲染之上的全能游戏框架，内置这些能力且文档/示例覆盖面广，官方有小程序/小游戏打包教程，更适合 agent 主导开发、快速产出。因此选择 Phaser，放弃继续沿用 PixiJS。
