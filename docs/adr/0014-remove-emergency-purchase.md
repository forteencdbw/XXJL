# 取消营业中紧急采购

副屏的采购按钮只在**打烊阶段**出现，营业中整颗按钮消失（底栏只剩「修为」）。营业中不再有任何补充灵材的入口：库存跑空就只能停止入座、流失客人，等打烊结算时看到「灵材不足流失 X 位」。打烊采购本身不变，仍是原价、瞬间到货，菜单页与副屏两个入口都保留；采买伙计也仍在打烊时按目标自动补货。

为什么：ADR-0013 之后掌柜已经并入员工，营业中不再有手动操作，急购是底栏上唯一保留的手动经营按钮。它同时带着双倍价、等货进度条和「掌柜急购中」的状态文字，让「营业中只看不点」的规则留了一条例外，玩法的重心又回到盯着库存点按钮。砍掉后营业中的决策全部前移到打烊：备多少货、排谁去采买，都是开张前的事。

代价：

- 规划失误没有营业中的补救手段，库存跑空的那一局只能认损失；这是有意保留的紧张感。
- 紧急采购的配置（耗时、装潢缩短、价格倍率）、进度条按钮组件与相关测试一并删除；将来若要恢复，需要重新设计而不是把按钮加回来。
