# 取消手动操作：掌柜视为员工，修为与经营脱钩

玩家不再亲手招待或烹饪。**掌柜**成为一名特殊员工：有属性、按伙计页的工作勾选与顺序自动干活、按干活次数成长，只是不能辞退、不领工资、不占雇人名额。营业中的「招待入座」「动手烹饪」和出菜行全部删除，玩家通过**分工**来经营。与此同时，招待改称**跑堂**，新增**传菜**环节（菜做好放在灶台上，跑堂端到桌上客人才开始吃），领座与传菜的耗时按实际走路距离和身法算。**修为**从经营中拆出来，成为副屏「修为」入口后的独立子系统，本期只占位：经营不再产出修为，境界与仙缘的加成全部停用，存档里的数值原样保留。

为什么：员工系统改成「谁都能做、按顺序派活」以后，玩家亲手操作和员工自动干活成了两套并行、互相抢活的规则（优先窗口、单线程掌柜、只有亲手才读口味和得修为），玩法的重心变得模糊。把掌柜并入员工，让经营的核心决策只剩一件事：**怎么排人**。修为原本绑在「亲自下厨」上（ADR-0005），没了手动它就失去了来源，与其硬找一个替代来源，不如单独设计成一个子系统。

推翻的决定：ADR-0003（手动到自动的成长曲线）与 ADR-0005（修为绑定亲自下厨）作废；ADR-0007 里为手动玩法加的优先窗口、口味只有亲手出菜才读、连击，一并删除。

代价：

- 失去即时操作的手感，营业中玩家主要是看和调整楼层视角；这是有意的取舍。
- 读口味改为自动（想吃的菜在菜单上就做），菜单选择接替了原来「手动读单」的策略位置。
- 已经飞升过的玩家暂时失去仙缘的售价加成，直到修为子系统重新设计。
