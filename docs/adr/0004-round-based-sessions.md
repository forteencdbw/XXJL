# 从永久挂机放置改为 60 秒回合制营业

此前游戏是永久运转的放置循环：只要在线，食客就不断到店、结算收益，没有任何回合边界。现在改为回合制：默认打烊，玩家点「开始营业」→ 选菜单 → 营业 60 秒 → 结算面板 → 回到打烊。

这么做是因为新加入的菜单系统需要一个明确的决策点：如果营业是连续不断的，"本次上哪些菜"就没有意义，玩家只会把所有菜都挂着。回合制把「选菜单 → 配置伙计 → 营业中执行 → 结算复盘」串成一个有始有终的循环，菜单、劳动力分配、瓶颈升级这些策略才真正落地。代价是放弃了放置类的核心卖点——玩家必须主动回来开局，且 `GLOSSARY.md` 里原本定义的「离线收益」被废弃（代码里其实从未实现过）。另一个代价是营业中的经营操作被收窄到只剩采购，雇人/升级/装潢全部收进打烊阶段，玩家不能边营业边调整。

这是一次有意为之的玩法结构转向，不是临时限制：如果以后要回到挂机形态，菜单系统的决策价值需要重新设计。
