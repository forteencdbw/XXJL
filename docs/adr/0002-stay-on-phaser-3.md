# 继续使用 Phaser 3，不升级到 Phaser 4

Phaser 4（npm `latest` 标签为 4.2.1）已于 2026-04-10 正式发布，不是 beta/rc，本身是可用的稳定版本。但它是对 Phaser 3 的从零重写，官方文档和 README 通篇只讲新的 WebGL 渲染架构，完全没有提及微信小游戏、字节跳动小游戏等非标准浏览器 JS 运行时，官方列出的导出目标里也没有这些平台；没有查到任何 Phaser 4 版本的社区适配方案（对应 Phaser 3 时代成熟的 weapp-adapter 路线）。本项目的发行策略是微信/抖音小游戏 + TapTap（H5）优先，已经是定下来的硬约束。在没有人验证过 Phaser 4 能在这些平台跑通之前贸然升级，有可能让整条技术栈在打包到目标平台这一步直接卡死。因此继续使用 ADR-0001 选定的 Phaser 3（`^3.90.0`），等后续有人验证过 Phaser 4 的小游戏兼容性后再重新评估迁移。
