# 修为与境界：把「修仙」做成可累积的第二条成长线

> 已被 [ADR-0013](0013-shopkeeper-as-employee.md) 取代：玩家不再亲手操作，掌柜视为员工，修为与经营脱钩。

此前游戏只有经营一条成长线：灵石 → 装潢/伙计 → 更多灵石。题材里的「修仙」只停留在名词层面，玩家没有任何修行进度，也没有长线目标；一个档玩到破产或腻了就结束。

现在加入修为与境界：**只有玩家亲自烹饪的菜**随食客离店产生 2 点修为，伙计出菜为 0，命中口味再 +1（仅亲自）；修为跨回合累积并驱动八重境界，每重给一项经营加成（售价、操作速度、客流、打烊灵材、伙计速度）。修为与境界随存档保留。

这么做有三个目的：

1. **补上题材的核心幻想**：经营是手段，修行才是修仙游戏的目的。境界越高的修士，酒楼自然越兴旺，两条线互相喂养。
2. **让「亲自下厨」有长期价值**：在此之前的自动化曲线里，雇到伙计后玩家就没有理由再动手，手动环节变成纯过渡。修为把「省时间」和「长修为」变成一组持续存在的取舍，而不是雇完人就退化成挂机。
3. **提供长线目标与存档意义**：境界阈值是跨越几十个回合的目标，存档让进度真正属于玩家。

代价与边界：

- 不做独立的打坐/闭关系统。修为只从经营行为产生，避免出现「关掉游戏干等」或「纯点击刷修为」的第二套循环。
- 为了不让「雇了灶上就再也抢不到桌子」堵死这条取舍：入座后有 1.5 秒优先窗口留给玩家，跑堂/灶上/采买可单独暂停自动（工资照付）。这是盲测发现「雇满伙计后玩家变观众」之后补的机制。
- 不做境界对菜品解锁的硬门槛。菜品仍由装潢等级解锁，境界只给数值加成，避免双门槛卡死玩家。
- 境界加成为固定档位而非自由加点，先验证「经营—修行」双线的节奏，再考虑天赋树。
- 飞升已在大乘处接入：重置本局、保留仙缘，作为长线目标；更复杂的转生天赋树仍未实现，先用「每重仙缘 +10% 售价」验证重复游玩的动力。

存档只写打烊阶段的稳定状态，营业中不落盘：否则中途刷新可以带着当日收益跳过工资与商行还款。这是为双线成长服务的完整性约束，不是临时限制。
