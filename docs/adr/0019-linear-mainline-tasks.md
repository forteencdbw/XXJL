# 线性主线任务：一次一个、手动领取、双类目标

新增任务系统，v1 只做一条 12 条的**线性主线**：同一时刻只有一个当前任务，完成后变成可领取，玩家在任务页点「领取」才发奖并切到下一条。目标分两类——**动作类**（开张、派采集、雇人、借款）从任务激活后计数；**状态类**（等级、楼层、声望）在激活时直接读当前值，已经满足就立刻可领取。进度与已完成清单进存档，**破产重开与飞升都保留**。任务页是子系统页，主界面右上角挂一条当前任务小条；主线走完后小条隐藏、任务页写「暂告一段落」。

为什么：任务的首要价值是把玩家按顺序引到现有系统上，一次一个当前任务比并行列表更能回答「现在该做什么」。动作类保证「亲手做一遍」的教学，状态类解决「玩家提前升过级、任务却要求再升一次」的挫败。手动领取让奖励与下一步都有存在感；保留完成记录则避免老玩家在破产/飞升后重学教程，也堵住重开刷奖励的路。

代价：

- 任务链是**严格线性**的：玩家卡在某条（例如等第 3 天借款）时，后面的任务不会提前出现；这是教学顺序的代价，内容表要避免过长或过难的卡点。
- 动作类目标只从激活后计数；玩家在激活前做过的事不算（例如先开了十次店，任务仍要求再开一次）。状态类不受此影响。
- 首批只有 12 条，主线在 Lv6 处收尾；支线、日常、重看教学都不在本期。
- 存档结构再变一次，升 v7，旧存档与 `LS6.` 导出码作废（延续「未上线不做迁移」）。
- 任务不锁定任何功能、不做按钮高亮；指引强度依赖文案与进度条，后续若要更强的引导需要单独设计。
