# 玩家时间原则：付费只压缩时间

本作的核心是**玩家时间**：只要肯花时间，就能体验到 99% 的内容；进度不会真正卡死，只会变慢（参考 Warframe）。付费与广告只能**压缩时间**，不能抬高上限，也不能产出时间拿不到的东西。剩下的 1% 只留给纯外观。以后每个系统设计都要先过这条审查：

1. **两种时钟**：产出资源的倒计时（采集、以后的闭关）走**墙钟时间**，关页面也照走；需要玩家参与的玩法（营业）走**在线时间**。
2. **仙玉可以换任何东西，前提是那样东西有一条纯时间的获取路径**。加速是最直接的形式；直接换资源、刷新招聘，本质上也是缩短培养时间，所以允许。外观可以只卖不肝，这是那 1%。
3. **不回退进度**：取消破产。余额为负进入**欠债状态**：不能营造、雇人、刷新招聘，欠债期间常客不来；不清档、不扣声望。出路是免费辞退伙计压低成本，或者继续营业慢慢还。
4. **随机稀有资质必须有时间保底**：灵根这类随机上限，要有招聘保底计数，再加一种能靠长期玩法拿到的改换道具（洗髓）。付费只让玩家更早拿到。
5. **不惩罚离开**：开市利是改为按累计开店天数计，不再要求连续；不做体力或每日次数上限，日常节奏只用正向的每日首次奖励。
6. **不吞已花的时间**：刷新或关闭页面时，按提前打烊结算本局已结账的收入，不再整局作废。
7. **修为**（待设计）：靠墙钟时间积累，突破境界这类关键节点要玩家在线手动决策。

为什么：时间是唯一对所有玩家都公平的资源，新玩家、老玩家和回流玩家花同样多的时间就能走到同一个位置。这样才能长线运营；想加速的玩家也有明确的付费出口，同时不会制造无法跨越的差距。破产清档、断签重置、刷新作废，都是在惩罚"已经花了的时间"，和这条原则冲突。

代价：

- 失去破产这个最强的经营压力。欠债状态如果太温和，日租和工资就形同虚设，需要靠"常客不来"和扩张冻结的数值来校准。
- 贷款 12 期还款本身就可能把余额扣成负数，借款的玩家可能长期处在欠债状态，进而被冻结扩张。实现时要确认还款节奏不会把"借钱扩张"这条路堵死。
- 放弃了"卖数值/卖上限"这条付费深度，付费收入只来自时间压缩与外观。
- 本 ADR 是方向性的。利是改累计已实现（#2）；破产→欠债、刷新结算、招聘保底、洗髓**尚未实现**，见 #1、#3、#4。

状态：放宽了 ADR-0018 的「仙玉唯一用途是加速」。
