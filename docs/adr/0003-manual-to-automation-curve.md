# 核心循环包一层手动早期阶段，自动循环降级为终态

此前验证过的核心循环（食客自动到店消费、自动入座、自动结算）是从零开始就全自动的放置循环。现在决定在它前面叠加一个手动早期阶段：吆喝、招待、烹饪三个环节默认需要玩家手动点击触发，各自对应一个伙计岗位（迎客/跑堂/灶上），雇到对应伙计才会把这个环节转为自动；原来验证过的全自动循环变成「四个岗位全部到岗」后的终态，而不是起始状态。

这么做是为了让游戏有「从亲力亲为到解放双手」的成长曲线，并把这条曲线和策略空间（先雇哪个岗位、雇几个）直接挂钩——如果一开始就是纯挂机，雇佣伙计的先后顺序就没有体验上的意义，玩家感受不到自己的策略选择。代价是核心循环的状态机复杂度明显上升（新增门口排队、耐心值超时、三个独立的手动触发点和各自的自动化开关），库存不足的检测点也从「到店/入座」挪到了「烹饪」这一步。这是一次刻意的范围扩张，不是对之前「最小闭环优先」原则的推翻——原来的自动循环没有被丢弃，而是被保留成这条曲线的终点。
