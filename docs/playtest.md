## 美术与沉浸感（2026-10-24 本轮）

本轮目标换成「第一眼被美术吸引、愿意盯着人物与互动、沉浸修仙」，因此把程序化美术整体重做，而不是继续调数值：

- **首次进入的标题页**：月晕、三层水墨远山、山门、朱印、题字「灵膳楼」与「一炉烟火 · 半盏仙途」，浮尘与呼吸的「推门入座」。流程是 标题 → 形象 → 直接进店（完整规则留在左栏「玩法」，不再强制甩一屏说明书）。
- **纵深背景**：屏幕固定的三层水墨山、山门、漂云与月晕；营业时镜头拖到门外也不会露出空白。
- **酒楼立面重绘**：翘角屋檐、瓦线、木柱横梁、窗棂、红帘、石阶苔痕、门前石径；两盏会轻摆的灯笼；招牌用楷体。
- **内景重绘**：木梁、山水挂画、置物架与酒坛、小挂轴、窗棂、石灶与炊具、门口红帘与暖光；灯笼与灶火常亮。
- **人物重做**：宽袖道袍、发髻/长发、会眨的眼睛、呼吸起伏；按身份带剑（剑修/玩家）、葫芦（丹修/魔道）、长须（长老）、草帽（凡人）、犄角（妖修）、托盘（跑堂）、锅勺（灶上）、酒旗（迎客）。入座与用膳出现碗筷热气，玩家下厨时身周升起灵气微光。
- **日常氛围**：每日开张题头「第 X 日 + 晴/灵雾/落英」；晴=浮尘、灵雾=低雾、落英=飘落花瓣；等菜/用膳/排队/伙计各有一句短台词，两位用膳客人偶尔互相搭话，口味上错会抱怨。**点任一人物**会回一句身份台词（剑修说剑、长老说慧根、魔道嫌天地太小），点按有 14px 拖动阈值，拖镜头不会误触。
- **信息减负**：桌卡只留「想吃什么 / 做哪道 / 入座」，用膳中不再顶卡片，避免遮住人物。

## 本轮长时体验修复（2026-10-24 晚）

针对上一轮长时盲测提出的「6 天 0 目标、总差一点」「只能干等随机到店」「食客没有名字/常客关系」三点，做了一轮以参与感为目标的改动：

- **目标可达 + 差一点也算数**：目标值改为 `接待 4+等级 / 收入 30+8×等级 / 口味 1+⌊等级/2⌋`（首日接待 5 位）；做到 60% 给半赏（灵石与修为各半），结算明确显示「差一点（3/5）· 半赏 +6 灵石、+1 修为」。旧目标下 6/7、61/64 这类一天白忙的情况不再发生。
- **吆喝**：营业中多一个「吆喝」按钮，10 秒冷却，点一下立刻来一位客人；队满或只剩最后 10 秒时给出提示且不进冷却。给等待中的玩家一件主动可做的事，而不是只能盯随机计时。
- **姓名与常客**：每位食客从本类型姓名池抽一个名字；落座后头顶挂名牌，点人物进入特写时字幕显示「姓名 · 人物特写」。吃到想吃的（或本来不挑、安稳吃完）的客人会记进常客簿（最多 6 位，跨日存档）；常客约 30% 概率带名再来、点名上次那道菜，头顶挂金色「· 常客」名牌，到访次数累计。飞升重开清空常客。
- **菜单页备货命中区**：给「备货 +N」文字按钮补了 12px 可点余量，和开张/返回按钮一致，避免只点中字形。

## 独立盲测（2026-10-24 晚，第一轮）

三名全新 AI 评审（美术总监 760×1320、休闲手机玩家 390×844、仙侠剧情玩家 390×844）各自用干净浏览器连玩两天，未读本文件；三人都愿意再玩。中位分：**第一眼 7（6–7.5） / 人物 6（5–6.5） / 沉浸 6（5–7） / 想再来一天 6（5–7）**。比上一轮的自评低，主要不是数值，而是信息层与失败反馈。

主要问题与处理：

- **灵材耗尽仍可领客入座**：HUD 仍是绿色，结算只说流失、不提示补货；美术总监第二天因此只成 2 位、流失 11 位。现在灵材 0 时禁止入座并提示先急购，灵材数字转红，结算新增「灵材不足流失 X 位（下次先备货或急购）」。
- **桌号/订单/姓名牌/气泡互相压字**：三人一致。已移除独立姓名牌；桌号上移到 FLOOR_Y-150、订单上移到 FLOOR_Y-120、气泡再上移，并在客人说话时暂时收起订单；特写字幕改为「姓名 + 情境台词 + 再点一次退出」，同时清掉聊天气泡。
- **特写停在空椅**：用膳 3s、特写 4.2s，客人吃完离店后字幕还挂着。现在用膳结束、排队超时或离店时若正在特写就立即退出；字幕台词按「排队/等菜/用膳/常客」取，避免排队客人说「结账」。
- **升级后目标不刷新、新菜不进菜单**：打烊期升级会立即按新等级重算当日目标，并把新解锁菜自动加入今日菜单（实测 Lv2 显示收入 46 而非 38，灵米粥已入菜单）。

## 已知边界

- 这是**本机自动化试玩 + 两次独立盲测（AI 评审）**，没有真人玩家样本、全球排行榜或第三方媒体评测，因此不能据此证明「全世界最好玩」；它证明的是「有一款完整、可复现、经过盲测并针对主要问题迭代过的游戏」。
- 盲测分数是各轮修复前的快照（第一轮 4/10、3/10；第二轮 5/10、5/10；第三轮 5.5/10、6/10）。第三轮设计师的测试中途被仓库 HMR 打断并重跑，前后可能不是同一版本；分数只代表盲测当时看到的东西，不是长期结论。
- 没有云存档/全球排行；跨设备迁移依赖手动 `LS1.` 导出码。
- 今日招牌、升级成本、手机字号、首日节奏与用膳特写已进入单盲评 2（8/7/6.5/7）；常客身份、急购提示、菜单 ◆、目标日志前缀在单盲评 2 后修；用餐 4.5s、两桌碰杯每 7 秒、人物卡 4.2×+卡内桌沿/淡墨山/朱印、全员入座坐姿/桌沿碗手、整桌点击看客、特写补回营业时间、第一天 90s、升级附赠 5 灵材、结算目标金框、HUD 列右移、4 桌交错、出菜标签缩短下移、卡内蒸汽/歪身碰杯/脸型指线/脸侧影/桌卡 19px、常客每日保底、招牌实际百分比、「下位 Ns」、菜单 0.995、升级 toast 在单盲评 3/4/5/6/7/8 后修。这些最后的改动只有本地脚本/截图核对，没有新的盲评分；修复后的完整复测工作流仍在启动约 27 秒后挂起。
- 底部按钮从 4 个变成 5 个，390px 手机宽度下最右的「吆喝」命中区约 35×47 CSS px；仍需真机手指复验。
- 6 日长跑证明了目标可达与常客跨日延续，但灵材是注入的、操作是脚本，且常客在脚本下都爱上同一道菜；不能替代真人长时体验。
- 音频只验证了乐句结构、开关与不报错，未做人耳听感评估。
- 全自动路线仍可能被部分玩家视为“看广告”；但修为只来自亲自下厨，想推进主线必须操作。
